Clacky Support

For support, open a GitHub issue at github.com/Stephanvs/clack/issues.

Before requesting help, include the Clacky version, Windows version, install source, audio output device, and which feature is affected.

Troubleshooting

  1. Open Clacky Settings from the tray icon and confirm Clacky is enabled.
  2. Confirm the selected sound pack loads and the volume is above 0%.
  3. Toggle Clacky off and back on.
  4. Switch the Windows default audio output device, then type again.
  5. Quit and relaunch Clacky.
  6. If startup at login is affected, disable and re-enable Launch at login from Settings.
